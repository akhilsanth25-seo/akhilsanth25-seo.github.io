## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Open your repository `akhilsanth25-seo.github.io`.
3. Upload the contents of this folder to the repository root (not the outer ZIP folder).
4. Commit to the `main` branch.
5. Wait for GitHub Pages to deploy.

## Before publishing
- Confirm the accuracy of project names, dates, responsibilities and reporting periods.
- Get client permission before making client screenshots public.
- Review screenshots for confidential information before publishing.
- Add your LinkedIn URL.
- Consider whether you want your phone number publicly displayed.
- The contact page uses an email link. A working form requires a form backend/service.
- Recheck canonical URLs if you later change the GitHub Pages domain or custom domain.

The screenshots are supporting evidence only. Tool estimates (SEMrush/Ahrefs) are not Google metrics, and reporting comparisons do not prove causation.
